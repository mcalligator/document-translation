As this solution comprises multiple modules, the prerequisites are split across those respective modules. Prerequisites for features not enabled can be ignored.

Common to all of them is the following:

- An AWS CodeConnections Connection to the source repository in GitHub for each AWS account used to deploy the solution (see Shared | Configuration | Source Service | GitHub page in this guide, or [Create a Connection](https://docs.aws.amazon.com/dtconsole/latest/userguide/connections-create.html) in the AWS Developer Tools Console for details of how to do this).
