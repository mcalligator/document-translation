Before using the Amazon Bedrock service, it is necessary first to gain access to the appropriate models. This can be done via the Amazon Bedrock console for the chosen region. The models enabled is your choice.

Please review [Amazon Bedrock]({{< ref "docs/readable/architecture/bedrock" >}}) for models supported by this solution.

Please follow the [Amazon Bedrock documentation for Model Access](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access.html) to enable the models in your AWS Account.
